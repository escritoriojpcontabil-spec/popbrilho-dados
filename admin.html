Configurar acesso

Faça isso uma vez em cada computador ou celular que for usar.

Use uma senha forte, com pelo menos 8 caracteres, misturando letras e números.
Como gerar a chave de acesso
  1. No GitHub, clique na sua foto (canto superior direito) → Settings.
  2. No fim do menu da esquerda: Developer settings → Personal access tokens → Fine-grained tokens.
  3. Clique em Generate new token. Nome: Painel POP BRILHO. Em validade, escolha o maior prazo.
  4. Em Repository access, marque Only select repositories e escolha popbrilho-dados.
  5. Em Permissions → Repository permissions, procure Contents e mude para Read and write.
  6. Clique em Generate token, copie o código que começa com github_pat_ e cole acima.
