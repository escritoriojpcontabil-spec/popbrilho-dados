# POP BRILHO — Site e loja online

- `index.html` — o site com a loja.
- `admin.html` — **painel do lojista** (login com senha) para editar produtos, preços, fotos e dados da loja.
- `produtos.xlsx` — onde ficam os produtos. O painel atualiza este arquivo sozinho.
- `logo.jpg` — logomarca.
- `fotos/` — fotos dos produtos (o painel cria e preenche esta pasta).

Endereço do painel: https://escritoriojpcontabil-spec.github.io/popbrilho-dados/admin.html
